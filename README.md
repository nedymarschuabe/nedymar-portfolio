# Nedymar Schuabe — Currículo

Site de currículo pessoal construído em React + Vite, com os dados profissionais de Nedymar Schuabe (Analista e Desenvolvedor de Sistemas).

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Stack

- React 19
- Vite 5
- CSS puro (sem frameworks)
